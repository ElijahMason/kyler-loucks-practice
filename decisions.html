Sheet 03, notes

Put the constraint on the sheet.

Decision line

Kyler Loucks writes the constraint, then chooses the tool that can live with it. The notes below are the ones he keeps on every drawing.

One account strategy

Accounts follow a single strategy. Each environment has a name. A resource without an environment name does not have a place on the plan yet.

A pipeline you can explain

Infrastructure is code. Delivery runs through a pipeline another person can walk. GitOps is the form that pipeline takes when the repository is the record production follows.

Security on the same sheet

Security is a design constraint. Identity, network reach, and the data boundary are drawn with the route, in the same pass as the rooms.

A bill you can read

Cost sits on the drawing as something a person can point at. You can hire a review of cost and reliability. The review names the bill and the failure modes. This sheet does not publish a claimed saving.

See also sheet 01, note N3. The account wall is part of the path.
