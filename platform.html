Sheet 02, plan

Four rooms, one platform.

Plan width

Kyler Loucks draws accounts, networks, delivery, and runtime before a service is added to any of them.

Accounts

One account strategy. Environments carry names before they carry resources. The boundary is a line you can point to on the plan.

Networks

The address plan comes first. CIDR is a drawing of ranges that must not collide. The same habit shows up in his public Medium note on IPv4 blocks for VPCs and subnets.

Delivery

Infrastructure is code. The pipeline is a path you can explain. GitOps belongs on the plan when production should follow the repository.

Runtime

Kubernetes fits when workloads need a shared platform contract. Serverless fits when the work is an event and the operational surface should stay small. The plan records which one the workload asked for.
